# Reflet

Reflet collects product feedback, tracks a roadmap, and publishes release notes. It also includes support conversations, surveys, status pages, and session capture for reporting problems in an application.

## Choose a starting point

- Use the hosted app at [reflet.app](https://reflet.app).
- Read the [user guide](https://www.reflet.app/docs/using-reflet) to set up a workspace and manage feedback.
- Add Reflet to an application with the [integration docs](https://www.reflet.app/docs).
- Work on this repository with [CONTRIBUTING.md](CONTRIBUTING.md).
- Deploy your own instance with the [self-hosting guide](docs/self-hosting.md).

The app uses Next.js and React, a Convex backend, and Better Auth. Bun workspaces and Turborepo build the web app, SDK, CLI, and browser widgets. See the [repository docs](docs/README.md) for architecture and operations notes.

## Report a problem

Use [GitHub issues](https://github.com/damien-schneider/reflet/issues) for reproducible bugs and feature requests. Follow [SECURITY.md](SECURITY.md) for private vulnerability reports.
