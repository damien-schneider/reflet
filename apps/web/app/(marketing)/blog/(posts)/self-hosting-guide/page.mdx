Reflet needs a Next.js web server, a Convex backend, and built browser widgets.

## Choose who operates Convex

- With managed Convex, you deploy the web app and backend functions; Convex operates the database and file storage. The repository includes Vercel configuration for this path.
- With self-hosted Convex, you also operate storage, networking, backups, and recovery. Start with [Convex's infrastructure guide](https://docs.convex.dev/self-hosting). This path has not been verified end to end for Reflet.

Email delivery, AI processing, billing, and GitHub integration still use external providers when enabled. Their credentials and webhooks are separate from hosting the app.

## Configure and deploy

The [maintained operator guide](https://github.com/damien-schneider/reflet/blob/main/docs/self-hosting.md) covers environment variables, auth origins, integrations, builds, and startup. For a local development environment, use [CONTRIBUTING.md](https://github.com/damien-schneider/reflet/blob/main/CONTRIBUTING.md).

Read Reflet's [source-available license](https://github.com/damien-schneider/reflet/blob/main/LICENSE) before deployment; it includes commercial restrictions and service-source requirements.
